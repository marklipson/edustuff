EDUCATIONAL STUFF

In this project are several educational projects which were used to teach various programming
concepts.  They are organized loosely into a sequence of "bags", allowing groups of programs to
share resources and build on one another.

Some teaching ideas follow...

Sections of code the student understands or is learning can be removed and replaced with TODO
comments that explain what is needed and include code snippets to get them started.  (Some remnants
of my original TODO comments remain but many were plowed under as part of the creative process.)

I hid most of the advanced math that was beyond the scope of the course in functions, allowing
the student to utilize it as they would any other library.  Or at least that was the aspiration;
more could be done toward that goal.

The lessons recorded here are somewhat of a 'best of' collection, starting halfway through the
course.  The full course would begin with creating a basic HTML page, styling it with CSS, adding
simple scripts, really basic canvas usage and so on.
